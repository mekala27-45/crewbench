# Crewbench repository contract

Build an inspectable comparison, not a presumed victory for delegation. Preserve actual_model, deterministic_baseline and scripted_runtime as separate modes.

Use Node 24.19.0 and the exact lockfile. Run npm ci, npm test and python3 -m unittest discover -s tests -p test_*.py. Run node scripts/migrate.ts only against the declared database. Run node scripts/check-api.ts against the bounded demo API. Run npx playwright test for the four browser views.

The public API accepts fixed baseline cases only. Never mount the Eve worker on the public host. The worker has only the role tools in src/runtime/tools.ts. Shell, files, web access, model-directed delegation and truth access are forbidden inside evaluated role contexts. Repository operator skills are not agent runtime skills.

Keep latent truth local until its publication is explicitly authorized. Do not put credentials, session capabilities or raw environment dumps in reports. The generated evidence corpus is fictional. Do not introduce employer or customer material.

Freeze prompts, model digest, template, budgets, corpus subset, adapter and grader before held-out inference. A changed input invalidates the freeze. Never substitute cases or discard failures. Reserve before dispatch, retain uncertain attempts and never blindly redispatch after a crash.

Protect artifacts referenced by claims. Do not delete or rewrite retained result branches. Render claims only from verified immutable evidence with source commit, digest, scope and measurement window. Missing measurements stay null with reasons. Do not tag a completed release until all mandatory acceptance rows are supported.

Complete work already authorized by the user. A failed automatic approval review is a boundary: do not retry the rejected secret transfer or protection change without specific user authorization. Keep unaffected work moving and report the concrete blocked action.


Portfolio experiment on authored synthetic release evidence. No production release is assessed or changed. Actual model runs, deterministic decisions and scripted runtime tests are reported separately. Results apply only to the declared cases, model, budgets and execution environment.
