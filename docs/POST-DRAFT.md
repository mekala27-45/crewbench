The hard part of this build was accounting for work after a failure. Crewbench gives each model request a reservation, each child result a receipt and each recovery check a fresh database read. The scripted failure suite verified 12 of 12 overlays. Model quality is reported separately.

The frozen comparison covered 12 paired cases. Solo produced 3 of 12 strict successes; split review produced 1 of 12. The observed split-minus-solo difference was -16.7 percentage points. No demonstrated useful model behavior under the registered utility floor.

These results are provisional: independent public-record grading is complete, but comparison with the private authored answer key is pending. The public site presents recorded evidence; final live API acceptance remains pending.
