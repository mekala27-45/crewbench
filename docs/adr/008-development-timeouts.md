The initial instruction-only model runs reached the synthesis role but repeatedly exhausted the request timeout after the specialists submitted. These failures remain in their original results branches.

The final pre-freeze operating point is the shared repository plan in evaluation/plan.json. Both methods receive the same request and trial ceilings. The model artifact, decoding, call, tool, byte and token allowances, fixed role partitions, cases and scoring rules remain fixed.

Development run 42115848494, source 43789f67432efa7c0720270a6268eaaccd8c0873, demonstrated native responses for solo, both specialists and synthesis and retained an accepted split-review assessment. The independent accounting audit must verify that bundle before freeze. Calibration run 42114717980 binds the same plan and model.

A concurrent review-branch candidate, source b8735be461cbececdbdd0713d00e73d349ce0115, used longer deadlines. Its run 42115794201 is exploratory and is not the selected configuration or evidence for the frozen comparison. Consolidation occurred using development evidence only; no held-out results informed the choice.

Framework watchdogs sit outside the registered trial deadline. The database deadline controls acceptance, and late output cannot alter an assessment. The CI evaluation window accommodates every planned row at its declared ceiling.
