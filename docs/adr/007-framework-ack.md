# Separate framework completion from inference

Status: accepted for development.

Eve ignores endsTurn inside delegated roles. Once a structured submission commits, the transport may return a zero-inference control acknowledgement to close the framework turn. Label that event framework_terminal_ack and exclude it from provider usage and assessment evidence. Every request sent to Ollama remains reserved and recorded. Evidence: installed Eve subagent documentation and src/runtime/provider.ts.

Portfolio experiment on authored synthetic release evidence. No production release is assessed or changed. Actual model runs, deterministic decisions and scripted runtime tests are reported separately. Results apply only to the declared cases, model, budgets and execution environment.
