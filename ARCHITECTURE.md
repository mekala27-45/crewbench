# Three execution planes

The HTTP plane serves short baseline requests on a Vercel Container. PostgreSQL stores sessions, immutable evidence, trial state, roles, resource reservations, provider attempts, tool receipts, child packets, joins, assessments and ordered events. Mutations lock the trial row. Capability scope and database admission survive process restart.

The worker plane runs Eve locally on a standard public Actions runner with an ephemeral loopback credential. A deterministic workflow invokes the solo role or the two fixed specialists followed by synthesis. Each evaluated role uses the same native Ollama model. A serialized transport gate reserves the exact canonical request before network dispatch. Application state is authoritative; framework persistence is not the source of correctness claims.

The report plane runs the Python grader after execution and renders sanitized static data. It never repairs outputs. GitHub Pages serves Compare, Case, Recovery and Method independently of API availability. Recorded actual data, deterministic decisions and scripted runtime tests retain their original evidence mode.

Accepted child slots are independent of lease generation. A worker takeover preserves them and increments fencing. A crash after dispatch intent without a durable response is indeterminate. The runtime does not assume external requests are exactly once.


Portfolio experiment on authored synthetic release evidence. No production release is assessed or changed. Actual model runs, deterministic decisions and scripted runtime tests are reported separately. Results apply only to the declared cases, model, budgets and execution environment.
